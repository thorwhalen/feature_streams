# Feature Streams Examples

Complete example applications demonstrating how to use the stream packages.

## Examples

1. **theremin.py** - Classic theremin using trackpad → synth
2. **keyboard_sampler.py** - Multi-voice keyboard-controlled synthesizer
3. **gamepad_dj.py** - DJ controller using gamepad
4. **voice_theremin.py** - Voice-controlled synthesizer
5. **stream_recorder.py** - Record and playback streams

## Running Examples

Each example can be run directly:

```bash
python examples/theremin.py
```

Press Ctrl+C to exit.

## Requirements

Examples may require different combinations of packages. Install all dependencies:

```bash
pip install -r requirements.txt
```

Or install specific dependencies per example (see comments in each file).
